⛷ KI-Spielwerkstatt: Skirennen

Wir bauen ein Ski-Spiel – ohne Code zu tippen. Ihr beschreibt, die KI programmiert.

QR-Code mit der Kamera scannen

rlen-source.github.io/skirennen

iPad-Tipp: In Safari auf Teilen → Zum Home-Bildschirm. Dann ist das Skirennen eine App mit eigenem Symbol.

So geht's

  1. Live Editor → „Basis-Spiel laden“ und ein Rennen fahren. Merkt euch eure Zeit!
  2. „Basis-Spiel herunterladen“ und die Datei in einem neuen Chat (ChatGPT oder Claude) hochladen.
  3. In Teil 1 einen Schritt wählen, „Prompt kopieren“ und im Chat einfügen.
  4. Den Code aus der Antwort kopieren (Kopieren-Knopf am Codeblock), im Live Editor einfügen → „Spiel anzeigen“.
  5. Spielen, vergleichen, nächster Schritt. Nach Teil 1 kommen in Teil 2 eure eigenen Ideen.

Wenn etwas klemmt

Antwort hört mittendrin aufPrompt „↻ Weiter“ schicken, dann im Live Editor „🧩 Fortsetzung anhängen“.
Spiel startet nichtPrompt „8½ Fehlercheck“ schicken und die neue Antwort einfügen.
Später weitermachen„💾 Meine Version herunterladen“ – später mit „📂 Datei öffnen“ zurückholen.
SteuernTastatur: ← → oder A / D. Tablet: Finger aufs Spielfeld legen und ziehen.

Die drei Bereiche im Spiel: 1) Einstellungen · 2) Hier darfst du ändern · 3) Spiel-Motor – nicht ändern.

⛷ AI Game Lab: Ski Race

We build a ski game without typing code. You describe it, the AI programs it.

Scan the QR code with your camera

rlen-source.github.io/skirennen/en

iPad tip: in Safari tap Share → Add to Home Screen. The ski race then opens like an app with its own icon.

How it works

  1. Live Editor → “Load base game” and do one race. Remember your time!
  2. “Download base game” and upload the file in a new chat (ChatGPT or Claude).
  3. In Part 1 pick a step, tap “Copy prompt” and paste it into the chat.
  4. Copy the code from the answer (copy button on the code block), paste it into the Live Editor → “Show / update game”.
  5. Play, compare, next step. After Part 1, Part 2 is for your own ideas.

If something goes wrong

The answer stops halfwaySend the “↻ Continue” prompt, then use “🧩 Append continuation” in the Live Editor.
The game does not startSend the “8½ Error check” prompt and paste the new answer.
Continue later“💾 Download my version” saves your version, “📂 Open file” opens it again.
SteeringKeyboard: ← → or A / D. Tablet: put a finger on the game and drag.

The three areas of the game: 1) Settings · 2) You may change this · 3) Game engine – do not change.
